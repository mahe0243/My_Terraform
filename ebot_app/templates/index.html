IAM Management

Manage IAM roles, users, and permissions.

GET /api/iam/roles

POST /api/iam/users

🪣

S3 Management

Create and manage S3 buckets and objects.

GET /api/s3/buckets
POST /api/s3/buckets
GET /api/s3/buckets/{name}/objects
DELETE /api/s3/buckets/{name}

✨ Features

  • EC2 Management: Launch, start, stop, and terminate instances
  • IAM Management: Create roles, users, and manage policies
  • S3 Management: Create buckets, upload files, enable versioning
  • RESTful API: Easy-to-use JSON API for all operations
  • Comprehensive Logging: Detailed logs for debugging and monitoring
  • Error Handling: Robust error handling with meaningful messages

🚀 Quick Start

Get started with ebot in just a few steps:

  1. Set up your AWS credentials in the .env file
  2. Install dependencies: pip install -r requirements.txt
  3. Run the application: python app.py
  4. Access the API at http://localhost:5000
  5. Start managing your AWS resources!

📚 API Documentation

All endpoints return JSON responses with the following structure:

{ "status": "success|error", "message": "Operation result message", "data": { ... } }

Authentication: Currently uses AWS credentials from environment variables. Plan to add API key authentication in future versions.

Rate Limiting: No rate limiting applied. For production, consider implementing rate limiting.

⚙️ Configuration

Environment Variables:

  • AWS_REGION - AWS region (default: us-east-1)
  • AWS_ACCESS_KEY_ID - AWS access key
  • AWS_SECRET_ACCESS_KEY - AWS secret key
  • LOG_LEVEL - Logging level (default: INFO)
  • LOG_FILE - Log file path (default: ./logs/ebot.log)
